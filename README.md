## Cara Menjalankan

Proyek ini adalah halaman statis tanpa dependensi tambahan. Tidak diperlukan instalasi atau server khusus.

1. Unduh atau clone repositori ini.
2. Buka folder proyek.
3. Klik dua kali pada berkas `index.html`, atau buka melalui peramban dengan cara:
   - **Chrome / Firefox:** `File → Open File → index.html`
   - **VS Code:** klik kanan `index.html` → *Open with Live Server* (jika ekstensi terpasang)
4. Website akan tampil di peramban.

## Fitur

- Informasi tiga paket layanan: Cuci Kiloan Reguler, Cuci Setrika, dan Cuci Express.
- Navigasi anchor menuju bagian Beranda, Layanan, dan Kontak.
- Informasi kontak: alamat, jam operasional, dan email.
- Desain responsif dengan pendekatan mobile-first (viewport 360 px hingga 1366 px).
- Aksesibilitas: skip link, fokus keyboard, dan markup semantik.

## Teknologi

- **HTML5** — struktur semantik (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **CSS3** — variabel, flexbox, grid, media query, `clamp()`
- Tanpa framework atau library eksternal
