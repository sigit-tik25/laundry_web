# Clean & Fresh Laundry

Website landing page profil UMKM **Clean & Fresh Laundry** yang menampilkan informasi layanan, cara pemesanan, testimoni, dan kontak. Dibangun menggunakan HTML5 dan CSS3 tanpa framework.

## Cara Menjalankan

Tidak diperlukan instalasi atau server khusus.

1. Unduh atau clone repositori ini.
2. Buka folder proyek.
3. Klik dua kali `index.html`, atau buka lewat **File → Open File** di Chrome/Firefox.

- Tanpa framework eksternal
